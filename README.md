# open-table-agent

MCP server and a minimal patch set that give AI agents full access to a self-hosted open-source Teable (Community Edition).

Status: planning. See `docs/decisions.md`.

## Build shim

The host has podman 4.3.1 / buildah 1.28, which rejects `COPY --link` (used by the upstream Teable Dockerfile). `e2e/bin/podman` (set as `OTA_PODMAN`) renders a derived Containerfile into `.work/build-shim/` with `--link` removed from COPY/ADD lines (`e2e/build_shim.py`) and builds that one. `--link` only affects layer caching, not the image. The same rendering prefixes upstream's `RUN pnpm fetch` with a pnpm-store seed of `xlsx-0.20.3.tgz` (cdn.sheetjs.com is unreachable): `python3 e2e/vendor_xlsx.py` fetches it via the download broker, verifies it against the lockfile sha512 and prints the `--podman-arg=--volume=...:/ota-vendor:ro` to pass to `sync-upstream.py --build`. The upstream `post-builder`/`runner` stages `apt-get` from deb.debian.org (unreachable): `e2e/apt_proxy.py` is a broker-backed local apt proxy (every Release/Packages/.deb fetched via `hermes-download`, checked against the signed Release/Packages sha256, cached in `.work/apt-cache/`). Build-only values (Prisma engine paths `PRISMA_QUERY_ENGINE_LIBRARY`/`PRISMA_SCHEMA_ENGINE_BINARY`, node-gyp `npm_config_nodedir`, the apt proxy `http_proxy`) are passed as `--build-arg`, never `--env`, so they are not baked into the image's `Config.Env`: the shim declares `ARG` for them after every `FROM` (ARG scope is per stage). `e2e/node_headers.py` fetches `node-v<ver>-headers.tar.gz` via the broker (sha256 from `SHASUMS256.txt`, itself fetched `--unverified`: only a detached GPG signature exists) and mounts it read-only for node-gyp (no nodejs.org access, so `cpu-features` builds as upstream). The single D2 build command is `python3 e2e/apt_proxy.py build -- [sync-upstream.py args]` (fetches Prisma engines + xlsx + node headers, runs proxy and build in one process). The upstream Dockerfile is never edited. `upstream.lock.json` is rewritten wholesale by `scripts/sync-upstream.py`, so the shim is documented here only.
